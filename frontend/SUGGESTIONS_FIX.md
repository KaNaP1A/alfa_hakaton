# Исправление выбора подсказки

Раньше поиск после выбора подсказки в некоторых сценариях использовал укороченный текст, а в интерфейсе показывал исходный запрос. Теперь поведение зависит от `selection_mode` ответа `GET /api/v1/suggest`.

- `replace_query_with_label` (демо): поиск отправляет `q` равным полному `label`.
- `selection_id` (ML): запрос отправляет исходный `q` и `selection_id` + `selection_generation`, а поле ввода и заголовок показывают полный `label`.

Фильтрация результатов сохраняет выбранную подсказку, уточнение использует исходную формулировку без одновременно переданного `selection_id`.

Проверить: `npm test`. Пример в интерфейсе: набрать «как открыть», выбрать «Как открыть ООО», проверить параметр `q` в Network. В demo он должен быть `Как открыть ООО`; в ML должны передаваться исходный запрос и идентификаторы выбора.
