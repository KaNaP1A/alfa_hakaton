# Обновление дизайна Альфа-Курса

Основа: опубликованная ветка `frontend` на GitHub и последний архив фронтенда из чата (15 ноября 2026). Если у вас есть новые локальные изменения, переносите их выборочно.

## Направление

- Цвета: красный `#EF3124`, основной текст `#171717`, фон рабочей области `#FFFFFF`, фон первого экрана `#F6F6F6`, вторичный текст `#606060`, границы `#E7E7E7`.
- Шрифт: Manrope (системный fallback — Arial).
- Главный акцент: поиск образовательных материалов. Декоративная буква «А» уменьшена и не отвлекает от поля ввода.
- Типографика: понятный заголовок без выделения отдельного слова, меньше надписей капсом и необязательных подпунктов.

## Изменения

- Первый экран стал ниже; каталог появляется раньше на странице.
- Обновлены заголовки, примеры запросов, текст кнопок и состояния.
- Кнопки поиска и фильтры имеют понятные области нажатия.
- Карточки упорядочены: тип → название → описание → действие, есть отметка просмотренного.
- Убрана малочитаемая мелкая типографика на мобильных и переработана сетка до 320px.
- Добавлены заметные стили `focus-visible`, поддержка `prefers-reduced-motion`, атрибуты `aria-pressed` у фильтров и навигации.
- Диалоги анкеты и материала закрываются клавишей Escape и возвращают фокус на исходный элемент.
- `src/design-polish.css` подключён последним и содержит отдельный слой дизайн-настроек, не меняя API.

## Запуск

```bash
npm install
npm run dev
npm test
npm run build
```

API Vite по-прежнему проксируется на FastAPI по адресу `127.0.0.1:8080`.
