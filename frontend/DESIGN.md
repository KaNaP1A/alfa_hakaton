# Альфа-Курс: дизайн сценария подбора

Software — работающий образовательный каталог для предпринимателей, который эксперт
проверяет на хакатоне перед интеграцией в kurs.alfabank.ru.

## Основа

Референс: https://kurs.alfabank.ru/. Просмотрены публичная разметка и стили сайта:
фирменный красный, светлые поверхности, геометричная типографика, карточки обучения.
Используется официальный SVG логотип. Изображения курсов и CSS сайта не копируются.
Локальный Onest с кириллицей заменяет проприетарные Styrene / Alfa Interface Sans.

Токены: белый #FFFFFF, поверхность #F5F5F6, текст #222225, вторичный #68696E,
красный #EF3124, действие #CE241B. Один шрифт Onest, веса 400 и 500, 600 для бренда.
Границы контента одинаковы: максимум 1280px, поля 48px / 24px на телефоне.

Скетч приложения:

    логотип       каталог / для вас / маршрут       профиль
    -----------------------------------------------------
    каталог / подбор
    Знания для вашего бизнеса       подбор по интересам
    [ Поиск по задаче                          Найти ]
    примеры запросов
    -----------------------------------------------------
    Материалы          количество          [форматы]
    [карточка]              [карточка]           [карточка]

Гостевой экран: тот же бренд и сетка, слева назначение продукта, справа вход и
регистрация. На телефоне компактная схема показывает фактическую последовательность
«задача — подборка — маршрут». Никаких фальшивых рейтингов, времени обучения,
изображений или цен.

## Ревизия относительно brief

Дилер предложил collage, gold/dark и Gabarito. Чёрно-золотой fintech не подходит
светлому Альфа-Курсу, Gabarito не решает кириллицу: применены собственные цвета
бренда и следующая подходящая пара Onest без моноширинных меток. Коллаж заменён
на настоящий рабочий поиск и каталог. Word-highlight не несёт действия в приложении:
вместо рекламного scroll-момента — один вход интерфейса и интерактивное уточнение
поиска. Полноэкранные рекламные секции затруднили бы оценку ранжирования;
плотность экрана определяется содержимым каталога. Это адаптация к brief приложения.

Voice: простой, деловой русский. «Найти материалы», «Изменить интересы»,
«Обновить маршрут». Говорим о задаче пользователя, без терминов ML/HTTP/токенов.

Проверяются: вход и регистрация, поиск/подсказки/уточнения, фильтры и пагинация,
рекомендации, маршрут, просмотр карточки и отметка завершения. Контракты API сохранены.

## Материалы

Логотип: официальный SVG Альфа-Курса (public/brand), шрифт: Onest, SIL OFL,
локальный WOFF2 subset в public/fonts (латиница и кириллица, 55 КБ).
Сторонние фотографии и изображения курсов не используются.
Обложки форматов — декоративная графика интерфейса; они не выдают себя за
оригинальные обложки конкретных курсов. Названия, описания, цены и статусы
при работе приложения приходят из API. Визуальные QA-страницы собираются отдельно
в dist/review-*.html на существующих synthetic/test fixtures и не входят в маршруты приложения.
