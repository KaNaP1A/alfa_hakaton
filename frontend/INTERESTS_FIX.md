# Исправление выбора интересов

- Удалены кнопки «Применить» и «Изменить анкету» из вкладки «Для вас».
- Категории становятся выделенными/снятыми сразу после клика.
- Каждое итоговое изменение сохраняется в профиле через `PUT /api/v1/me/profile`.
- После успешного сохранения обновляется `POST /api/v1/recommend`.
- Пока запрос выполняется, не показывается устаревшая подборка.
- Несколько быстрых переключений не отправляют параллельные конфликтующие обновления.
- При ошибке восстановится сохранённое состояние и появится понятное сообщение.
