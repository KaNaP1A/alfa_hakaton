# Демонстрация: публичный снимок + вымышленные карточки

Это локальный прототип интерфейса для обсуждения конверсии и удержания. Он показывает
публичный снимок, собранный 15 ноября 2026, карточки из бэкапа и 48 вымышленных примеров.
В каталоге 138 курсов, 9 вебинаров, 7 калькуляторов и 12 вымышленных уроков. Для 225
курсов, вебинаров, уроков, подкастов и калькуляторов есть условные цены и себестоимость.
Суммы придуманы для демонстрации; шесть из них ориентированы на сохранённые наблюдения
цен с сайта, но совпадение карточки и актуальность стоимости не подтверждены. Цены и
себестоимость всегда обозначены как условные; оплат и доступа нет.
Открытые карточки содержат ссылку на исходную страницу, но их доступность и текущая цена
не проверены. «Продолжить тему» — пример: после нажатия на синтетическую карточку
показывается вымышленный курс той же темы, выбранная тема хранится в localStorage.

Отдельный сайт `demo_catalog/server.py` использует поиск подстроки и демонстрационное
чередование источников. В основном React-приложении раздел демо-каталога также позволяет
сравнить подбор по теме и подбор с учётом бюджета и условной прибыли. Он запрашивает
существующий поиск бэкенда; карточки с совпадающим ID используют его результаты, а
часть курсов сопоставлена по названию с явной пометкой непроверенного совпадения.
Остальные отбираются по словам. Две близкие по теме карточки могут поменяться местами
из-за условной прибыли; модель вероятности покупки здесь не используется. Ни один из
режимов не меняет действующие цены или платёжные данные бэкенда. Реальные покупки,
конверсия и удержание этим демо не измеряются. См. [аудит каталога](AUDIT.md).

## Запуск после клонирования репозитория

Из корня проекта, с Python 3.11 или новее:

```sh
python3 demo_catalog/server.py --catalog data/demo_catalog.json --port 8767
```

Откройте http://127.0.0.1:8767/. Чтобы пересобрать демонстрационный каталог из
публичного снимка и модели, предварительно скачайте модель через Git LFS:

```sh
python3 demo_catalog/build_catalog.py \
  --public data/public/pages/materials.jsonl \
  --historical models/recommender/catalog/generation-c9cd546ed3bf-2c54d178a129-1641b706f281/catalog.json \
  --calculators data/public/calculators/materials.jsonl \
  --observations 05_code/experiments/alfa_public_courses.json \
  --output models/sandbox/mixed_catalog_new.json
```

Скрипт требует **новый** путь и не перезаписывает имеющиеся файлы. Новые локальные
результаты и базы в `models/sandbox/` исключены из Git. Сервис слушает только localhost.

Проверки из корня:

```sh
python3 -m unittest discover -s demo_catalog/tests -v
node --check demo_catalog/app.js
cd frontend && npm test
```

Визуально и функционально проверены поиск, смешанная выдача, явные метки источника и
сценарий «Продолжить тему». У результата нет подтверждения роста продаж или удержания.
