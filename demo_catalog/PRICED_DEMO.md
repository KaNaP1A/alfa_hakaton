# Цены и подбор в демо-каталоге

В демо-каталоге 1 157 карточек: 138 курсов, 9 вебинаров, 7 калькуляторов, 12 уроков, 59 подкастов, 713 статей и 219 документов. Из них 48 карточек полностью вымышлены, остальные взяты из публичного снимка или бэкапа. Семь калькуляторов восстановлены из `data/public/calculators/materials.jsonl`, три вебинара — из бэкапа. Ещё шесть вебинаров и все 12 уроков вымышлены. Дубликаты по нормализованному названию и типу проверены; варианты курсов с различающимися названиями сохранены.

## Учебные цены

Для 225 курсов, вебинаров, уроков, подкастов и калькуляторов записаны `demo_offer.price_rub` и `demo_offer.cost_rub`. Это **условные данные**, включая себестоимость: они не являются действующими ценами, правами доступа, вероятностями покупки или платёжными предложениями. Статьям и документам платные демопредложения не назначаются. Поле исходной цены `price` у публичных карточек остаётся `unknown`.

Диапазон курсовых цен задан с учётом [каталога Альфа-Курса](https://kurs.alfabank.ru/courses/) и сохранённых наблюдений `05_code/experiments/alfa_public_courses.json`. Для шести карточек найдено однозначное совпадение названия с сохранённой ценой; запись помечена `title_match_not_verified`, а цена всё равно показывается как условная. Остальные суммы и все себестоимости генерируются детерминированно. Источник наблюдения не доказывает, что нынешняя стоимость, ID или доступ карточки совпадают.

## Как работает демонстрация

В основном React-приложении откройте **«Поиск» → «Демо: все карточки» → «Подбор с учётом цены»**. Введите тему, при необходимости задайте максимальную цену и включите «Учитывать условную прибыль».

1. Клиент запрашивает существующий поиск бэкенда с настоящей моделью. Для карточек с общим ID учитывается позиция модели. Для 19 курсов связь сделана по совпадению названия и явно помечена непроверенной; она не превращается в подтверждённый ID. Остальные подходящие карточки отбираются простым совпадением слов. При недоступности поиска отображается сообщение и используется подбор по словам.
2. В подбор попадают только условные платные предложения по теме и в пределах заданного бюджета. Переключатель прибыли может менять местами только соседние предложения с близким тематическим баллом. Прибыль вычисляется как условная цена минус условная себестоимость. Результат объясняется в карточке, исходная позиция по теме показывается при перестановке.
3. Это объяснимое правило для демонстрации, **не** переобученная модель вероятности покупки. Оно не изменяет работу `/api/v1/recommend`, данные бэкенда, доступ, реальные цены или платёжные операции. Карточки публичного сайта и синтетические предложения в этой демонстрации не доказывают реальных возможностей покупки.

## Проверка

Из корня `integrated`:

```bash
python3 -m unittest discover -s demo_catalog/tests -v
cd frontend && npm test && npm run build
```

Для проверки реальной модели, HTTP-бэкенда и функции подбора на временной SQLite-базе:

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 \
PYTHONPATH=05_code/src 05_code/.venv/bin/python scripts/smoke_priced_demo.py
```

Проверка создаёт временную тестовую базу с искусственными правами доступа и запускает два сервиса на `127.0.0.1`. Она проверяет наличие совпадений с моделью, бюджет и изменение порядка при включении условной прибыли; затем тестовые сервисы и база удаляются. Она не обращается к рабочей базе и не выполняет покупки.

Каталог воспроизводится скриптом `demo_catalog/build_catalog.py`, параметры указаны в [README](README.md). Реальные права, себестоимость и результат влияния на выручку потребуют данных платформы и отдельного эксперимента.
