## Что показали примеры

- Для кофейни найден материал о выборе франшизы. «День бариста» и Pop-up магазины в верхних позициях показывают недостаток понимания конкретной задачи запуска.
- Для лояльности сотрудников система ошибочно поднимает материалы о лояльности клиентов. Нужны разметка сущностей/контекста и последующий reranker; результат не следует демонстрировать как качественный ответ.
- В нормализованном каталоге слово Frontend не встречается. Ближайшие результаты нерелевантны точному запросу; требуется gate отсутствия ответа. Текущий CLI обозначает coverage=unknown и возвращает кандидатов для исследования.
- Для договора аренды найдены документы, но гарантийное письмо выше самого договора: это ещё один пример для разметки и ранжирования.
