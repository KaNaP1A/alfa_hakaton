# Локальный поиск и рекомендации Alfa

Экспериментальный прототип трека рекомендаций. Рабочий профиль: BM25 + локальная E5 и CatBoost (`relevance`); обучение использовало слабые синтетические пары, независимое качество пока не подтверждено. История и учебный план — отдельные контентные эвристики. Данные и модели не включаются в Git.

Диагностический пул для независимой человеческой разметки текущей выдачи: [инструкция второго этапа](docs/STAGE2_EVALUATION_2026-11-12.md). Старые запросы уже были видны разработке; это не новый закрытый тест.

## Запуск на этом компьютере

Из `05_code` выполните одну команду либо откройте `Запустить демо.command`:

```sh
PYTHONPATH=src HF_HUB_OFFLINE=1 .venv/bin/python -m alfa_reco serve --relevance --no-llm --port 8000
```

Откройте `http://127.0.0.1:8000/`; лаборатория — `/lab`. Постоянный порт сохраняет доступ к профилю браузера между запусками. Если порт занят, остановите другой экземпляр или задайте другой `--port`; профиль в браузере привязан к адресу и порту. `Открыть лабораторию.command` запускает ту же модель сразу на странице лаборатории. Остановка — Ctrl+C.

Проверка: задайте запрос «Хочу открыть кофейню»; в `/lab` отметьте просмотр или завершение курса и посмотрите рекомендации и план. `GET /health` сообщает поколение и режим; поиск дополнительно проверяется через интерфейс. Старые `hybrid`/`ensemble` — отдельные исторические эксперименты и требуют их собственных совместимых артефактов.

## Docker

Установите Docker с Compose. Каталог и модель не входят в образ и должны быть безопасно переданы отдельно. В `05_code`:

```sh
docker compose up --build
```

Откройте `http://127.0.0.1:8000/`. По умолчанию монтируются только для чтения `./artifacts/catalog` и `./artifacts/models/multilingual-e5-small`. Их можно заменить переменными `ALFA_CATALOG_DIR` и `ALFA_ENCODER_DIR` в `.env`. Путь к encoder из старого манифеста переносится во временную копию манифеста внутри контейнера; отпечаток модели проверяется до старта. Исходные артефакты не меняются. В контейнере приложение слушает `0.0.0.0`, но Compose публикует порт только на loopback хоста. Это development-сервер, не публичный сервис. Docker в исходной среде аудита недоступен, поэтому контейнерный запуск ещё требует проверки на машине с Docker.

## Данные, зависимости и перенос

Нужны Python 3.11+ и совместимые локальные артефакты. Верхнеуровневые версии закреплены в `requirements-relevance.txt` и включённых им файлах; полного lock-файла транзитивных зависимостей пока нет. Для новой машины:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e . -r requirements-relevance.txt -r requirements-dev.txt
```

Для передачи бэкенду подготовьте отдельный минимальный комплект без `source.sqlite` и дампа с помощью `scripts/prepare_backend_bundle.py`. Команды создания, проверки и переноса, контракт API и разделение ответственности приведены в [инструкции для бэкенда](docs/BACKEND_HANDOFF.md). Каталог и модели содержат производные данные выгрузки: передавайте их только разрешённым получателям безопасным способом. Нельзя смешивать каталог, векторы и модель от разных поколений. Исходный PostgreSQL backup не публикуйте.

Для самостоятельного восстановления данных нужны совместимый PostgreSQL `pg_restore`, предоставленный backup и обучение/публикация совместимого relevance bundle. Команда `build` создаёт каталог и подсказки, но сама по себе **не создаёт готовый relevance bundle**. Историческая команда `embed` строит MiniLM, а не E5-профиль. Подробности: [передача бэкенду](docs/BACKEND_HANDOFF.md), [обучение](docs/RELEVANCE_TRAINING_2026-11-12.md), [исходный алгоритм](../docs/ALGORITHM_SPEC.md).

Снимок не подтверждает актуальные цены, ссылки, право пользователя на контент или конверсию. Сервер намеренно доступен только локально; развёртывание требует отдельной авторизации и проверки прав. Поисковые оценки не являются вероятностями.

## Проверки

```sh
PYTHONPATH=src HF_HUB_OFFLINE=1 .venv/bin/python -m unittest discover -s tests -v
.venv/bin/ruff check src tests scripts
.venv/bin/ruff check src --extend-select S
```

Тесты API используют временный loopback-порт. Для разметки и исследовательских отчётов могут понадобиться дополнительные локальные артефакты, не включённые в Git. Данные остаются в браузере и на компьютере.
