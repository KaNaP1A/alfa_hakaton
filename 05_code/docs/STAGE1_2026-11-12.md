# Первый этап: запуск и данные

## Выполнено

- Основной запуск, ML-запуск и лаборатория используют `relevance`, без LLM, на постоянном порту 8000. CLI `search` по умолчанию также выбирает `relevance`. Старый гибрид по-прежнему доступен явно и требует собственных индексов.
- Compose содержит приложение, публикующее порт только на loopback хоста; каталог и E5 монтируются только для чтения. Для запуска внутри контейнера создаётся временная копия манифеста с локальным путём к encoder; отпечаток и другие хеши проверяются. Исходные файлы не изменяются. PostgreSQL оставлен дополнительным профилем.
- Для калькуляторов статус берётся из единственной неудалённой записи `CalculatorPages` с тем же ID. Неоднозначные и неподтверждённые записи исключаются. Создано новое поколение каталога и совместимый индекс/ранжировщик. В нём 1476 карточек, 1125 доступны поиску. Все 1469 прежних карточек сохранены; профиль старого поколения совместим.
- Три публичные страницы проверены по отдельности: курс «Как управлять командой», статья «Первый сотрудник: подготовка к найму», калькулятор НДФЛ. Для этих совпадений типа и исходного slug ссылки добавляются при загрузке. Остальные адреса не угадываются и не считаются проверенными. Проверка ссылки не подтверждает нынешние права пользователя или цену.
- На `/lab` карточки умеют открывать проверенные ссылки; добавлен фильтр калькуляторов.
- 178 тестов прошли. Ruff lint и security-проверка проходят. Локально проверены запуск HTTP, health, поиск калькулятора, `/recommend` и `/development-plan`. Подготовка временного bundle для контейнера проверена на реальных артефактах локально. YAML Compose проверен синтаксически.

## Сравнение поколений

Фиксированная конфигурация переобучена на слабых парах, без выбора нового режима по test. На старой неполной ассистентской разметке validation pooled NDCG@5 снизился с 0,6807 до 0,6607, test изменился с 0,7605 до 0,7612. Это небольшие диагностические выборки с уже раскрытым test, не независимая оценка. Новый вариант активирован для добавления проверенных типов; старое поколение сохранено для отката. Детали доступны локально в `artifacts/stage1_training_20261112/report.json`.

## Не завершено

- Docker недоступен на этой машине: сборка образа и запуск Compose в реальном Docker не проверены. Версии верхнеуровневых пакетов закреплены, полного переносимого lock-файла нет.
- Подтверждены только три индивидуальные ссылки; остальные требуют проверки маршрутов и актуальности владельцем платформы. Не выдаём предположения за действующие адреса.
- Для запуска на другом компьютере требуются безопасно переданные совместимые каталог и encoder. Они не включены в Git. Локальный запуск вне контейнера по-прежнему требует обновить абсолютный путь encoder в копии манифеста при переносе.
- Качество персонализации, смысловые ошибки и полноценный учебный маршрут относятся к следующим этапам. Добавление калькуляторов не является доказательством улучшения рекомендаций.
