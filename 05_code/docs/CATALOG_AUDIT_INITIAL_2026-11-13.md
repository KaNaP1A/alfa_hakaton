# Начальная проверка каталога и источника

Проверены активное поколение каталога и соответствующий локальный снимок `source.sqlite`. Скрипт проверяет хеши каталога и источника по манифесту. Всего в каталоге 1476 сущностей; из них 1125 имеют типы, допускаемые пользовательским поиском. В таблице ниже рассматриваются эти 1125 карточек; 351 элемент глоссария в них не входит.

| Поле | Нет значения |
| --- | ---: |
| Название | 0 |
| Описание | 5 |
| Публичные темы | 482 |
| Теги | 64 |
| Поле `industries` | 931 |
| Текст `body` | 84 |

Отсутствие `body` не всегда является ошибкой: отдельные типы материалов не обязаны содержать текст в данном поле, а платные уроки не должны автоматически попадать в индекс. Повторяющихся `entity_key` во всём каталоге не обнаружено.

## Откуда пропуски фасетов

Сравнение текущих карточек с исходными связями даёт следующую картину:

- **Темы:** 460 карточек имеют исходные связи только с темами `IsPublic=false`, которые текущий импорт исключает; ещё у 15 карточек связей нет, а у 7 нет строки `ContentSettings`.
- **Теги:** у 57 карточек нет связей в исходной таблице; ещё у 7 нет строки `ContentSettings`.
- **Отрасли:** у 924 карточек нет связей в исходной таблице; ещё у 7 нет строки `ContentSettings`.

Название поля `industries` шире, чем отрасли: в нём есть также метки «Без опыта», «С опытом» и служебная метка. Из 194 заполненных карточек только у 169 есть отраслевая или рыночная метка; у 25 — только остальные значения. Поэтому утверждать, что отрасль подтверждена у всех 194, было бы неправильно.

Семь карточек без `ContentSettings` — добавленные калькуляторы. Для карточек с разрешёнными исходными связями расхождений значений с каталогом в этом сравнении не обнаружено. Это проверка значений трёх фасетов, а не полная проверка всех полей и связей выгрузки.

Названия, описания и аудитория всех 1125 доступных поиску карточек сверены с соответствующими строками снимка после очистки HTML: расхождений не найдено. Пять пустых описаний также пусты в источнике, поэтому они не заполнялись предположениями. Добавлен экспорт для бэкенда: он сохраняет идентификаторы, метаданные и подтверждённое происхождение заполненных полей, проверяет хеши и прерывается при расхождениях. Правила и команда приведены в [инструкции передачи](BACKEND_HANDOFF.md#метаданные-каталога-для-бэкенда).

Непубличные темы не следует автоматически показывать пользователям или добавлять в поисковый индекс: назначение признака и разрешённость внутреннего использования отдельно не подтверждены. Отсутствующие отрасли нельзя выдумывать. В исходных карточках отдельного происхождения фасетов нет; подготовленный экспорт указывает таблицы связей и справочников для заполненных значений после проверки соответствия источнику.

Фактические актуальные ссылки, цены, публикация и права доступа в этом аудите не проверялись; по договорённости их актуальность обеспечивает бэкенд. Каталог и рабочие индексы в ходе аудита не менялись.

## Воспроизведение

Из каталога `05_code`:

```sh
PYTHONPATH=src .venv/bin/python scripts/audit_catalog_facets.py \
  --catalog artifacts/catalog --output /tmp/catalog_facets_new.json
```

Скрипт читает исходную SQLite-базу в режиме только для чтения и не сохраняет данные отдельных пользователей. Результат зависит от активного поколения каталога. Сводка по текущему снимку сохранена в `artifacts/annotation_pool/large_v2_20261113/reviews_20261113/catalog_facet_audit.json`.
