# Эксперимент: каталог, цены и синтетические запросы

Дата: 2026-11-15. Эксперимент локальный, действующий каталог и модель не переключались.

## Данные

- Основа — изолированный каталог `artifacts/offline_mixed_index_20261115_v1`, ранее собранный из экспортированного бэкапа, публичного снимка и демосинтетики. После удаления точных повторов в обучающем наборе: 1476 карточек бэкапа, 185 публичных и 12 синтетических. Исходные данные не удалялись.
- Ещё 1200 обучающих карточек выбраны из [azrai99/coursera-course-dataset](https://huggingface.co/datasets/azrai99/coursera-course-dataset), ревизия `ccd36c1660fee9610d5262e7517d8397c343168b`. Скачано 6645 строк; 5057 прошли тематический фильтр до выборки. Карточка набора заявляет Apache-2.0; права на исходные материалы Coursera отдельно не проверены. Внешние курсы помечены `huggingface_training_only` и не являются предложениями Альфы.
- Для 18 совпадений типа и нормализованного названия в экспериментальном каталоге оставлена одна карточка; остальные ключи помещены в `quarantine.json`. Это не доказывает совпадение платформенных ID. Между внешними строками найдено 48 повторов названий. Смысловые дубли и похожие названия могут оставаться; автоматическое слияние фактов по одному названию недопустимо.
- Файл `taxonomy_annotations.jsonl` содержит записи для всех 2873 материалов: 2288 получили хотя бы одну из шести тем по ключевым словам, 585 — пустые метки. Темы и совпавшие слова являются непроверенной эвристикой. Для внешних карточек сохранены и навыки из исходного набора; на бэкапные карточки автоматически найденные темы записаны отдельно и не изменяют оригиналы.
- В сохранённом публичном снимке 1092 страниц поле цены отсутствует. Отдельный файл с семью наблюдениями содержит 5 однозначных совпадений по нормализованному названию и 2 без такого совпадения. Ссылки между карточками и ценами не подтверждены. Они сохранены в `observed_price_candidates.json` с флагом `current_offer_verified: false`, а семь наблюдавшихся сумм использованы только как возможные точки диапазона для моделирования предложений. Случайная выдача такой суммы материалу не означает, что это его цена.

## Запросы и разметка

Сформировано 7218 синтетических запросов по шаблонам с 10 ролями и 10 вариантами формулировок. Для поиска использованы 700 запросов к 700 разным нормализованным названиям: 350 внешних курсов, 298 карточек бэкапа, 49 публичных и 3 синтетических. Метка «этот материал подходит» — слабое предположение на основании источника запроса, а не оценка человека. Формулировки копируют название, поэтому они недостаточно разнообразны для проверки свободных жизненных запросов.

Разделение на train/validation/test детерминированное по нормализованному названию; 668 карточек проверочных семейств исключены и из слабых отрицательных примеров. Проверка файла обучающих пар подтвердила отсутствие их ключей среди синтетических пар. В логах существующий тренер называет любой переданный локальный файл `local_model`; в этом запуске запросы шаблонные, LLM их не генерировала.

## Результаты

- Переобучен CatBoost-ранжировщик (700 слабых групп, 4200 пар) на общем экспериментальном индексе; используется прежний E5-энкодер, заново он не обучался. Конфигурация была зафиксирована заранее. Независимых человеческих оценок нет.
- На одинаковом каталоге прежний ранжировщик против нового: NDCG@5 на validation **0,6105 → 0,5702**, на test **0,7430 → 0,6931**. Это прежние запросы с оценками ассистента, всего четыре размеченных кандидата на запрос; неразмеченные материалы учитываются как нули. Эти результаты не доказывают реальную величину ухудшения, но не дают оснований переключать модель.
- На 80 синтетических отложенных шаблонах с полным названием новая модель поставила целевой материал первым 80 раз, прежняя — 69 раз. Считается порядок до фильтра допуска. Названия скопированы в запросы, поэтому проверка лёгкая и не доказывает качества на реальных запросах.
- Две модели CatBoost для интереса и покупки обучены на 2000 вымышленных сессиях; тест — 500 сессий, ещё 500 — стрессовый сценарий. Использованы 1673 дедуплицированные карточки бэкапа/публичного снимка/демо, внешние курсы исключены. ROC-AUC теста: интерес **0,6919**, покупка **0,6341**. Все цены, предложения и события симуляции искусственные, даже если величина цены встречалась в наблюдении. Это проверка работы симулятора, а не прогноз реальной конверсии или выручки.

## Артефакты и воспроизведение

Все ниже — локальные файлы в `05_code/`, не коммитятся согласно `.gitignore`:

- `artifacts/external_courses/` — скачанный CSV и данные о ревизии; SHA-256 CSV `997a4813b0b9f0d808512f5370a85ae710ed7ecd06dc11c3029253310c3ed4a7`.
- `artifacts/persona_corpus_20261115_v1/` — каталог, разметка, запросы, карантин, цены-кандидаты, манифесты и список исключённых карточек. Повторная сборка дала те же хеши каталога и запросов.
- `artifacts/persona_index_20261115_v1/` — отдельный поисковый индекс.
- `artifacts/persona_ranker_20261115_v2/` — веса, пары и отчёты `report.json`, `comparison_same_catalog.json`, `persona_holdout.json`.
- `artifacts/commercial_persona_sim_20261115_v4/` — две коммерческие модели и отчёт симуляции.

Команды с новыми именами выходных каталогов:

```bash
cd 05_code
export PYTHONPATH=src:scripts
.venv/bin/python scripts/prepare_persona_corpus.py --output artifacts/persona_corpus_RETRY
.venv/bin/python scripts/select_persona_training.py --corpus artifacts/persona_corpus_RETRY --output artifacts/persona_corpus_RETRY/training_queries.jsonl --heldout-output artifacts/persona_corpus_RETRY/heldout_entity_keys.json --limit 700
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python scripts/index_persona_corpus.py --corpus artifacts/persona_corpus_RETRY --output artifacts/persona_index_RETRY
```

Для обучения ранжировщика передать сформированный список проверочных карточек через `--weak-exclude-ids`. Запускать `scripts/train_relevance.py` без `--install`, указывая новый индекс, выбранные локальные запросы, исключённые ключи и `--fixed-config-from-report artifacts/relevance_v1/training/report.json`. Для симуляции использовать `scripts/train_mixed_catalog_simulation.py --exclude-origin huggingface_training_only --observed-prices <observed_price_candidates.json>` и изолированный каталог.

Дальше необходимы разнообразные запросы без копирования названий, независимая ручная разметка релевантности и отдельный тест, подтверждение прав и актуальных цен, а для проверки экономической цели — реальные события и контролируемый эксперимент. Подтверждённые цены и платформенные ID нельзя выводить из совпадения названий.
