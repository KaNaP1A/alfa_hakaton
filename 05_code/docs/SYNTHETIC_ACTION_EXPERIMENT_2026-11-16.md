# Синтетические сценарии на объединённом каталоге

16 ноября 2026 года отдельно обучены два CatBoost-классификатора: для
вымышленного вовлечения и вымышленной покупки. Они не подключены к выдаче и не
являются моделями вероятности реальной покупки.

Использован локальный объединённый индекс и 1352 ID, которые были одновременно
в индексе и видны в проверке подключённого снимка. Словарные термины исключены,
уроки включены. Группы одинаковых нормализованных названий одного типа не
пересекали разбиения: 947 карточек в train, 135 в validation, 270 в test.
Сгенерированы 5000 обучающих, 1000 проверочных, 1500 тестовых и 1500 стрессовых
сессий. Из 50 000 обучающих строк 22 543 были синтетически «просмотрены»;
непоказанные строки не считались отказами.

| Синтетическая задача | AUC test | Log loss test | Log loss постоянного прогноза |
| --- | ---: | ---: | ---: |
| Вовлечение | 0,6642 | 0,6241 | 0,6828 |
| Покупка | 0,6247 | 0,2807 | 0,2910 |

Стрессовый набор моделирует более высокую чувствительность к цене: AUC 0,6880
и 0,6297 соответственно. Значения получены на действиях, сгенерированных
формулами самого симулятора, и не описывают поведение клиентов. Например,
тестовый срез покупки содержит лишь 4 положительных события уроков и 5 вебинаров;
делать выводы по этим типам нельзя. Могут оставаться тематически похожие записи;
строго разделены только группы нормализованных названий и типа материала.

Для воспроизведения на этом локальном снимке:

```bash
cd integrated
PYTHONPATH=.:backend:05_code/src .venv/bin/python scripts/export_visible_catalog_keys.py
cd 05_code
PYTHONPATH=src .venv/bin/python scripts/train_mixed_catalog_simulation.py \
  --catalog ../models/unified/ИМЯ_АКТИВНОГО_КАТАЛОГА \
  --allowed-keys ../models/unified/simulation-allowed-keys.json \
  --output ../models/unified/НОВАЯ_ПАПКА_ЭКСПЕРИМЕНТА \
  --train-sessions 5000 --test-sessions 1500
```

Имя активного каталога записано в `models/unified/ACTIVE.json`. Исходный запуск
и модели сохранены локально в `models/unified/experiment-actions-2026-11-16/`;
там же находятся полный отчёт, манифест, веса и обучающие сценарии. Эта папка
исключена из Git. Реальные доступы, цены, заказы, возвраты и экспериментальные
группы нужны отдельно для обучения и оценки коммерческой модели.
