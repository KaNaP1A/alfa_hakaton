# Локальный интерфейс для проверки алгоритма

Откройте в Finder папку `05_code` и дважды нажмите **Запустить демо.command**. Откроется Terminal, загрузится локальная модель, затем браузер со страницей:

**http://127.0.0.1:8000**

Окно Terminal нужно оставить открытым. Для остановки нажмите в нём Ctrl+C. Повторно запускать файл при уже работающем сервере не нужно. Если порт 8000 занят другой программой, используйте команду ниже с `--port 8001`.

## Запуск из терминала

Из папки `05_code`:

```bash
PYTHONPATH=src python3 -m alfa_reco serve --hybrid --open-browser --port 8000
```

Без загрузки модели, только BM25 и подсказки:

```bash
PYTHONPATH=src python3 -m alfa_reco serve --open-browser --port 8000
```

На этом компьютере модель и библиотеки установлены. При переносе установка описана в [README](../README.md). Для запуска UI не нужны Node.js, сборка фронтенда, API-ключи или доступ в интернет. HTML нельзя просто открыть как файл: необходим локальный сервер для работы с каталогом.

## Что можно проверять

- Подсказки после паузы во вводе, связанные темы и коррекцию опечаток.
- Выбор подсказки мышью либо клавишами ↑/↓ и Enter; Escape закрывает список.
- Поиск без выбора подсказки и поиск с выбранным уточнением. Исходный текст не заменяется. При редактировании уточнение сбрасывается.
- BM25 и гибридный режим, тип материала, количество результатов.
- Карточки с реальными названиями, описаниями, доступом и темами. Длинные описания раскрываются по кнопке. Уроки показываются внутри курса.
- «Режим исследования»: оценки, совпавшие слова, позиции каналов, JSON результата и копирование всей выдачи.

Примеры: `открыть коф`, `лояльность сотруд`, `договор арнеды`, `Frontend` в BM25. Для последнего ожидается пустая выдача. Гибридный поиск пока может возвращать близкие, но нерелевантные материалы — интерфейс не исправляет ограничения ранжирования.

Ссылки на материалы показываются только при наличии проверенного формата абсолютного адреса в каталоге. Для большинства slug адрес не придумывается. Проверка доступа в UI — отображение метаданных, не реальная авторизация на сайте.

## Технические детали

Статические файлы лежат в `src/alfa_reco/web/`. Их раздаёт тот же сервер, что и API: никаких проблем с CORS и отдельного frontend-процесса. Разрешены только четыре статических маршрута: `/`, `/app.js`, `/app.css`, `/favicon.svg`. База и остальные файлы проекта через HTTP недоступны. Введённый/полученный текст вставляется через textContent. Внешних шрифтов, аналитики и CDN нет; установлен Content-Security-Policy.

Ввод: debounce 150 мс, AbortController и проверка версии ответа, учёт IME. Изменение текста отменяет устаревший поиск; результаты подписаны исходным запросом. Ошибка подсказок не блокирует кнопку поиска. При перезапуске с новым каталогом устаревший ID уточнения отклоняется.

Проверено: 27 Python-тестов, Ruff и security-правила, проверка синтаксиса JS и launcher. В браузере вручную проверены подсказки, выбор клавиатурой, гибридная выдача, режим исследования, пустая выдача BM25 и фильтр документов. Это локальный тестовый интерфейс; на сайт Альфы ничего не публиковалось.
