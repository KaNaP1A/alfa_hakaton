# Диагностика профильного ранжирования

Проверка выполнена на 268 полностью согласованных вопросах существующего диагностического набора: 202 train и 66 validation. Новые вопросы и оценки не создавались. Запросы известны при разработке; профили искусственные, а оценки характеризуют релевантность материала запросу, не соответствие конкретным предпочтениям человека.

Для каждого вопроса зафиксированная выдача `relevance` сравнивалась с результатом профильного модуля. Проверены цель без дополнительных предпочтений; отдельно предпочтение курса, отрасль «ритейл», опыт `beginner`, стадия `launch`; также сочетание этих четырёх предпочтений. История в этом эксперименте не подставлялась. Варианты профиля одинаковы для всех вопросов и не представляют реальных пользователей.

Без предпочтений порядок top-5 совпал с исходным **на всех 268 вопросах**. На 66 вопросах validation предпочтение курса изменило порядок у 14, «ритейл» — у 8, сочетание — у 20. По отдельности `beginner` и `launch` порядок top-5 в этом прогоне не изменили; это не означает, что признаки отсутствуют во всём каталоге или никогда не могут влиять на выдачу.

Изменённая выдача может содержать материал вне оценённого пула. Такие материалы не считаются нулями: соответствующий вопрос исключается из парного сравнения конкретного варианта. Для сочетания предпочтений на validation остались **64 из 66** вопросов; два результата оказались без оценки. На одинаковом подмножестве получились следующие показатели, усреднённые по семействам:

| Показатель | Исходная выдача | Сочетание предпочтений |
| --- | ---: | ---: |
| P@5 | 0,4069 | 0,4069 |
| MRR@5 | 0,7238 | 0,7100 |
| NDCG@5 | 0,8063 | 0,7954 |

Для NDCG исключаются вопросы с нулевым идеальным DCG; идеальный порядок строится только внутри оценённого пула. На train при том же сочетании осталось 192 из 202 вопросов, NDCG изменился с 0,7751 до 0,7664, MRR — с 0,7259 до 0,7146. Неизвестные материалы исключались аналогично.

В этом диагностическом эксперименте сочетание предпочтений несколько снизило оценки **общей релевантности запросу**. Это не доказывает, что предпочтения вредны конкретному пользователю: человек может ценить подходящий формат или отрасль, а таких оценок в наборе нет. Но и утверждать, что профиль повышает качество, по этим данным нельзя. Коэффициенты остаются эвристиками; потребность в дальнейшей калибровке сохраняется.

## Воспроизведение

```sh
PYTHONPATH=src HF_HUB_OFFLINE=1 .venv/bin/python scripts/evaluate_profile_diagnostic.py \
  --pool artifacts/annotation_pool/large_v2_20261113 \
  --judgments artifacts/annotation_pool/large_v2_20261113/reviews_20261113/judgments_adjudicated.jsonl \
  --output artifacts/annotation_pool/large_v2_20261113/reviews_20261113/profile_diagnostic_NEW.json
```

Каталог, модель, замороженный пул и согласованная разметка должны быть доступны локально. Скрипт проверяет хеши пула, ранжирования и каталога; не оценивает отложенные 72 вопроса и не создаёт метки. Результат относится к конкретным файлам и конфигурации, не к конверсии, обучению или промышленной эксплуатации.
