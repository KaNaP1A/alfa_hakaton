# Локальный эксперимент по дообучению E5

12 ноября 2026 г. на CPU Mac выполнен эксперимент с отдельной копией `intfloat/multilingual-e5-small`; в работающем профиле E5 и CatBoost не заменены. Исходная E5 сравнивалась с дообученной **только как векторный поисковик**, без BM25, CatBoost, порогов допуска и остальных правил конечной выдачи.

## Данные и обучение

Из прежних 800 слабо размеченных синтетических запросов к реальному каталогу исходные названия материалов разделены на группы: 175 групп / 485 запросов для обучения, 58 / 159 для validation и 59 / 156 для test. У каждого запроса положительным считается материал, на основе которого запрос был создан; это автоматическая разметка, другие материалы тоже могут подходить. На обучении для каждого примера случайно выбран один негатив из ранее подготовленных кандидатов. Материалы с названиями целевых групп validation и test исключены из обучающих негативов.

Обучение: один проход, парная логистическая функция потерь по разнице косинусных сходств, AdamW, шаг 0,00002, batch size 8, ограничение обучающей последовательности 128 токенов, два CPU-потока. При измерении использовалась длина 384, как в исходном профиле. По validation до просмотра test заранее выбран кандидат, если NDCG@5 больше исходной модели. Скрипт: [`scripts/finetune_e5_weak.py`](../scripts/finetune_e5_weak.py); команды запускаются из `05_code`:

```bash
PYTHONPATH=src TOKENIZERS_PARALLELISM=false .venv/bin/python scripts/finetune_e5_weak.py \
  --output artifacts/e5_finetune_runs/NEW_RUN
```

Папка результата должна быть новой. При другом запуске этот test уже раскрыт и не является новым закрытым тестом. Скрипт использует существующие локальные каталог, E5, модель и файл `artifacts/relevance_v1/training/training_preferences.jsonl`. Новый энкодер сохранён локально в `artifacts/e5_finetune_runs/weak_20261112/candidate_encoder/`; артефакты Git не отслеживает.

## Результаты векторного поиска

При поиске по всем 1118 подходящим карточкам по одной автоматически размеченной исходной карточке на запрос:

| Набор и метрика | Исходная E5 | Дообученная E5 |
|---|---:|---:|
| Validation, NDCG@5 | 0,900 | 0,925 |
| Validation, MRR@10 | 0,881 | 0,916 |
| Validation, Recall@10 | 0,975 | 0,987 |
| Test, NDCG@5 | 0,874 | 0,906 |
| Test, MRR@10 | 0,860 | 0,891 |
| Test, Recall@10 | 0,949 | 0,962 |

Измерено положение лишь одного известного исходного материала, а не всех релевантных ответов. Высокие значения частично объясняются тем, как созданы запросы; они не являются NDCG итоговой системы и не показывают влияние на живых пользователей. Запросы ранее использовались при обучении CatBoost, хотя сам E5 до этого не дообучался. Поэтому этот набор не является независимым тестом всей системы.

Аудит не нашёл точных совпадений нормализованных или канонизированных запросов между частями, а также точного совпадения полного текста целевых карточек validation/test с положительными или выбранными отрицательными карточками обучения. Это не исключает смысловых пересечений, одних и тех же шаблонов или попадания похожих текстов в неизвестные данные первоначального предобучения E5. Снимок агрегированных результатов, разделения и аудита — в [`evaluation/e5_finetune_weak_2026_11_12`](../evaluation/e5_finetune_weak_2026_11_12/).

## Почему рабочая модель не переключена

Для новой E5 необходимо заново построить векторы всех полей, обучить CatBoost на новых признаках и измерить всю цепочку вместе с правилами выдачи. В текущем проекте ещё нет достаточно независимого набора с человеческими оценками разных кандидатов. Одного улучшения поиска исходного материала недостаточно, чтобы утверждать, что порядок результатов для людей улучшился. Старые индекс и CatBoost нельзя просто совместить с другими весами E5: проверки целостности это блокируют.
