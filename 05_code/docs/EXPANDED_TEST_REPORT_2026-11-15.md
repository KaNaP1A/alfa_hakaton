## Интеграция с настоящей моделью

Проведена отдельная проверка бэкенда с реальным E5/CatBoost-сервером и временной SQLite-базой. Затем отдельно запущены два HTTP-сервиса на локальных портах с новой временной базой и тестовым каталогом из 1125 материалов. Проверены 14 сценариев: каталог, холодный старт, пустой план, четыре поисковых запроса, подсказка, уточнение, повтор события, рекомендации, план после события, устаревшее поколение и выход.

База и учётная запись были временными. Признаки публикации и доступа для теста заданы искусственно; он не подтверждает реальные права, актуальные цены, поведение PostgreSQL или визуальное отображение сайта в браузере. Использовалась действующая модель в `models/runtime`, а не экспериментальная смесь.

## Проверка 240 формулировок

Составлены 80 запросов по 20 темам: исходные 20 ситуаций и по три переформулировки. Для каждого дополнительно созданы два контролируемых варианта — с вежливым обращением и с указанием, что человек новичок. Всего 240 запросов на каждую из двух моделей, то есть 480 вызовов поиска с действующим фильтром выдачи. Для тем задан один или несколько предварительно выбранных ассистентом материалов.

| Формулировка | Запросов | Исходная модель: известная карточка в топ-5 | Смесь: известная карточка в топ-5 |
|---|---:|---:|---:|
| Без добавленного префикса | 80 | 55 | 56 |
| Вежливый префикс | 80 | 54 | 63 |
| «Я новичок в бизнесе» | 80 | 50 | 54 |
| Всего | 240 | 159 | 173 |

Ни в одном из 480 результатов не было повторяющихся ID внутри выдачи. В каждом варианте модели 228 из 240 запросов содержали хотя бы один известный материал в списке извлечённых кандидатов; до топ-5 доходили значения из таблицы. Пустая выдача встретилась трижды у каждой модели.

**Разнообразие источников:** в 1115 показанных карточках исходной модели 165 были из публичного снимка (14,8%), а у смеси — 75 из 1115 (6,7%). Публичная карточка встречалась в 106 запросах из 240 против 59 у смеси. Это результат именно этого зависимого набора запросов, а не оценка реального трафика. Снижение важно для поставленной цели разнообразить выдачу; пока оно не объяснено, смесь не следует переключать в рабочий поиск.

Пример чувствительности формулировки: при добавлении «Я новичок в бизнесе» исходная модель потеряла известную карточку из топ-5 в 8 из 80 пар и добавила её в 3 других; смесь — потеряла в 5 и добавила в 3. Это не следует трактовать как влияние реальных личных характеристик пользователей: тестируется только добавление текста.

Результаты по темам без префикса (4 формулировки на тему) показали, что обе модели не вывели отмеченный подкаст о кассовом разрыве ни разу из четырёх. Статью о взыскании задолженности показали в одном случае из четырёх. Это конкретные кандидаты для проверки поиска и фильтра допуска.

**Ограничения:** запросы и связи с карточками составлены ассистентом, а не взяты из реальных логов и не проверены независимыми людьми. Есть лишь 20 тем, первоначальные запросы и некоторые темы уже использовались в предыдущих экспериментах. Для каждого запроса перечислены не все подходящие материалы: отсутствие отмеченной карточки не означает, что остальные результаты нерелевантны. Это диагностическое покрытие, не беспристрастная оценка общего качества, выручки или удержания.

Разметка для независимой проверки: [лист оценки](NATURAL_REVIEW_2026-11-15.md). Файлы сценариев находятся в `data/relevance_review/natural_stress_20261115.json` и `data/relevance_review/natural_styles_20261115.json`; локальные подробные отчёты — `05_code/artifacts/natural_assessment_20261115_v1/stress_80.json`, `style_240.json` и `source_exposure_240.json` (папка артефактов не включается в Git).
