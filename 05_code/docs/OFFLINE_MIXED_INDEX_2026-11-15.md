# Этап 5: экспериментальный индекс смешанного каталога

## Статус

Подготовлен и проверен **отдельный офлайн-индекс**, не согласованный каталог платформы.
Он не включён в основной сайт, не изменяет действующие `CURRENT.json` и не используется
для принятия решений о публикации, покупке, ценах или доступе. Этап 5 полностью не
закрыт: для промышленной версии сначала нужна сверка из этапа 4.

Базовое поколение `generation-c9cd546ed3bf-2c54d178a129-1641b706f281` содержит
1 476 записей, из них 1 125 доступны поиску. К нему добавлены 203 записи открытого
снимка без точного совпадения исходного ID и 12 вымышленных карточек. 889 совпадений
по исходному ID и типу не добавляются повторно: сохраняется историческая карточка.
В эксперименте **1 691 запись**, из них **1 340 поисковых**; 351 термин глоссария
в пользовательский поиск не входит.

Новые идентификаторы детерминированы и начинаются с `<kind>:offline-`, они **не ID
платформы**. Заголовки и описания — из локального публичного снимка; синтетические
карточки явно отмечены, их условные цены не попадают в цены каталога. Новые публичные
темы, права, цены, ссылки и публикация не выдумываются. Совпадение ID не подтверждает
текущую доступность. Происхождение записей и ограничения снимка описаны в
[аудите](../../demo_catalog/AUDIT.md).

Построены словари BM25 в памяти `SearchEngine`, подсказки и E5-векторы полей в отдельном
каталоге. Использованы **те же E5-веса и прежний CatBoost Ranker** без переобучения и
перенастройки. Они подходят по именам признаков и кодовым хешам, но качество на новом
каталоге нужно проверять; техническая совместимость не доказывает качества.

## Результаты сравнения

Сравнение выполнено на 193 существующих синтетических запросах с частичной разметкой,
без подбора параметров. Test — 39 запросов из 9 семейств; он ранее уже был просмотрен.
Числа NDCG, P и MRR — средние по семействам; `judged@5` учитывает долю пяти позиций,
на которые существует оценка. Неразмеченные результаты при расчёте pooled-метрик
считаются нулевыми. Для новых карточек независимых оценок нет.

| Test, 39 запросов | Исходный | Экспериментальный |
|---|---:|---:|
| NDCG@5 pooled | 0,761 | 0,745 |
| MRR@5 pooled | 0,909 | 0,893 |
| P@5 pooled | 0,213 | 0,206 |
| Доля размеченных позиций из пяти | 0,233 | 0,225 |
| Доля известных релевантных ID до фильтра, среднее по запросам | 0,936 | 0,923 |
| Доля известных релевантных ID в выдаче, среднее по запросам | 0,564 | 0,551 |
| Пустые ответы | 0 | 0 |

На всех 193 запросах точный порядок top-5 совпал в 98 случаях, два запроса были пустыми
в обоих вариантах; новых пустых ответов и превращений пустого в непустой не было.
Среднее число рассмотренных после ранжирования кандидатов — 60 для обеих версий.
Доля найденных ID до фильтра относится к заранее размеченным положительным карточкам,
а не к полноте всего каталога. Это не измерение влияния пользовательских прав.

Срез test по типу размеченного положительного материала: статьи — 31 запрос,
NDCG 0,744 → 0,733; курсы — 5 запросов, 0,800 → 0,726; документы — 8 запросов,
0,815 → 0,815. Запрос может попасть в несколько срезов. На таких малых и частично
размеченных группах выводы о качестве новых материалов делать нельзя.

По точным названиям отдельно найдены новый курс, подкаст и вымышленный курс; попытка
загрузить новый модельный индекс со старым каталогом отвергнута. Работающий указатель
остался на исходном поколении. Две независимые сборки на этой машине дали идентичные
SHA-256 каталога, нормализованных данных и векторов, поэлементная разница векторов — 0.
Это не гарантия побитового совпадения на другом оборудовании.

С учётом небольшого снижения метрик и неполной разметки **не активировать этот индекс
как действующий**. Результаты не показывают выручку или удержание и не доказывают, что
новые материалы не релевантны. Необходимы согласованный каталог и проверка совместимости
со стороны платформы.

## Повторение

Из `integrated/05_code`, с подготовленными окружением и runtime-моделью:

```sh
PYTHONPATH=src HF_HUB_OFFLINE=1 OPENBLAS_NUM_THREADS=2 TOKENIZERS_PARALLELISM=false \
  .venv/bin/python scripts/build_offline_mixed_index.py \
  --output artifacts/offline_mixed_index_NEW

PYTHONPATH=src HF_HUB_OFFLINE=1 OPENBLAS_NUM_THREADS=2 TOKENIZERS_PARALLELISM=false \
  .venv/bin/python scripts/compare_offline_mixed_index.py \
  --candidate artifacts/offline_mixed_index_NEW \
  --output artifacts/offline_mixed_index_NEW/comparison.json
```

Оба выходных пути должны быть новыми. Комплект из двух текущих сборок и отчёт со
срезами находятся локально в `artifacts/offline_mixed_index_20261115_v1/` и `_v2/`;
артефакты исключены из Git. Код сборки и сравнения хранится в `scripts/`.

Проверки: `PYTHONPATH=src HF_HUB_OFFLINE=1 .venv/bin/python -m unittest discover -s tests`
— **300 тестов прошли**; `ruff check` для двух новых скриптов и теста — без ошибок.
