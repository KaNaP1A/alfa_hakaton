# Снимок проверки 1000 + 120 сценариев

[Объяснение результатов и методики](../../docs/CHALLENGE_1000_2026-11-12.md). Все вычисления выполнялись на Mac; текущая модель не обучалась на этом корпусе.

- `summary.json`: 976/1000 основных проверок; 72/120 дополнительных сложных; 152 теста кода.
- `dev.jsonl`, `test.jsonl`: 800/200 сценариев, разделённых по семействам до оценки. Test раскрыт и выполнен один раз; для следующего подбора нужен новый holdout.
- `oracle_dev.jsonl`, `oracle_test.jsonl`, `catalog/`: полностью заданная структурная разметка 400 задач × 280 вымышленных документов. Это искусственная задача, не human gold.
- `dev_report.json`, `test_report.json`: все результаты, включая ошибки, исходные хеши кода и SHA модели. NDCG@5 искусственного test — 0,95642.
- `freeze_before_test.json`: данные и код финального dev-прогона; все записанные SHA проверены при запуске test до просмотра результатов. Примечание фиксирует исправленное несовпадение абсолютных и относительных ключей файлов при записи протокола.
- `stress_cases.jsonl`, `stress_report.json`: дополнительные длинные запросы, отрицания и отвлекающий контекст. Созданы после основного закрытого прогона; новым holdout не являются.
- `automatic_ratings.jsonl`: автоматические черновики 814 реальных пар, append-only история. При повторах пары используется последняя строка. `automatic_manifest.json` хранит происхождение, `automatic_metrics.json` — полные pooled-метрики. Автоматический test NDCG@5: relevance 0,3814, исторический hybrid 0,5723. Это сигнал для проверки, не независимая человеческая оценка.
- `real_pool_*`: фиксированные задачи, кандидаты, исторические ранжирования, пустые человеческие столбцы и результат строгого человеческого evaluator: 0 завершённых задач. Существующие задачи публичны разработчику, этот пул не новый слепой test.
- `checksums.json`: SHA256 файлов снимка. Большие encoder, векторы и ranker остаются в `artifacts/`; их идентификаторы сохранены в отчётах.

Архив не меняет старые метрики и не заполняет человеческие оценки синтетическими. Неполная разметка, полный искусственный oracle и автоматические оценки реальных карточек имеют разные ограничения и не складываются в одну оценку качества.
