# Синтетический подбор: зафиксированный эксперимент

[Полное объяснение обучения ML и результатов](../../docs/ML_AND_SYNTHETIC_HOLDOUT_2026-11-12.md).

- `manifest.json`: SHA-256 файлов раздельных validation/test каталогов и запросов, хеш выбранного CatBoost и статус одноразового test.
- `validation/`, `test/`: вымышленные карточки, запросы и отдельно лежащие искусственные оценки. В данные, индексируемые поиском, оценки и поля oracle не включены. Каталоги не пересекаются по ID и точным нормализованным названиям.
- `validation_report.json`: результаты 286 сочетаний весов. Максимум NDCG@5 = 0,925 разделили 153 варианта.
- `selection.json`: выбор до test, хеши данных, модели, отчёта и исходного evaluator. Выбрано BM25 0 / MiniLM 0 / E5 0 / CatBoost 1. `frozen_evaluator.py` соответствует записанному хешу.
- `test_report.json`: одноразовый test — NDCG@5 0,700; MRR@5 0,700; P@5 0,280; 6 из 20 выдач пустые. Действующий профиль и выбранные веса выдали одинаковые результаты на 20/20 запросов. Повторный запуск test штатно отклонён.
- `leakage_audit.json`: проверки точных нормализованных пересечений, ID и отделения меток. Смысловые пересечения и данные предобучения encoder полностью не проверяются.
- `model_provenance_correction.json`: исправление слишком широкого описания источников в историческом манифесте. Установленная модель и её исторический манифест не изменялись.
- `checksums.json`: SHA-256 снимка. Индексы и веса encoder хранятся локально в `artifacts/`, а не включаются в этот снимок.

Ограничения: 30 семейств, по две формулировки; искусственные оценки 0/3 без человеческой проверки; два положительных материала повторяют текст в разных форматах; нет запросов с заведомым отсутствием ответа. Метрики не измеряют качество на реальных пользователях. Этот test уже раскрыт и не подходит для дальнейшей настройки.
