# Этап 2: уроки и подсказки

Реализовано 11 ноября 2026 года. Инструкции: [AUTOCOMPLETE.md](docs/AUTOCOMPLETE.md).

## Результат

- 1 469 карточек материалов, 62 исходные таблицы и 102 128 строк сохранены.
- Проверены 512 связей уроков с курсами. Допущены 235 связей (235 уникальных уроков) в 21 курсах.
- Остальные связи: 149 — курс не допущен, 66 — разделы, 61 — доступ к метаданным не подтверждён выбранной политикой, 1 — удалённая запись. Это количества связей, не уникальных уроков.
- 4 440 подсказок: названия, подтверждённые короткие фразы и значения справочников.
- Команды suggest, serve; HTTP /suggest, /search, /health. Поиск сохраняет исходный запрос и учитывает ID выбранной подсказки.
- Курс может находиться по названию урока; уроки не размножают карточки курса в результатах.

## Фактически проверено

- Повторный импорт воспроизвёл source.sqlite, catalog.json и suggestions.json; совместимые embeddings сохранены.
- Embeddings пересчитаны после добавления уроков и фильтрации справочников: 1 469 × 384.
- 26 автоматических тестов: COPY/SQL-подобные данные и имена, HTML/ссылки, доступ уроков/предков/циклы/даты, опечатки/контекст/границы ввода, повреждённые индексы, устаревший выбор, файловая блокировка, HTTP и параллельные запросы.
- Ruff lint (E4/E7/E9/F/I/B/UP), отдельные security-правила для src, форматирование, compileall, синтаксис shell.
- В security-проверке вручную разобраны 3 предупреждения: SQL-идентификаторы экранируются, значения передаются параметрами; pg_restore запускается списком аргументов без shell, путь backup абсолютный, бинарник задаётся локальным оператором, не HTTP-запросом. Для этих проверенных конструкций оставлены точечные noqa с обоснованиями и регрессионный тест SQL-подобного имени. Глобальное отключение security-правил не применялось.
- Исправлены найденные незакрытые SQLite-соединения. Тесты запускаются с ResourceWarning как ошибкой.

## Практические границы

Это рабочий этап алгоритма, не обещание отсутствия будущих дефектов. API локальный, без production-развёртывания и интеграции в сайт. Права конкретного пользователя не проверяются. Формулировки автоматически извлечённых фраз требуют оценки человеком; нет полного морфологического/синтаксического анализа. Веса ранжирования не обучены.

Выбор темы уточняет поиск, но общий hybrid без выбора по-прежнему может смешивать лояльность сотрудников/клиентов и выдавать ближайшие нерелевантные материалы для Frontend. В подсказках no_match реализован, в основном dense-поиске полноценного no-answer gate ещё нет. CatBoost, LLM и персонализация не подключены. Нативный PostgreSQL/Docker по-прежнему не проверен запуском.
