# Этап 3: полные тексты, измерение, CatBoost

В проект добавлены индекс доступных статей и уроков, поиск по полям и фрагментам, воспроизводимый набор оценок и обучение экспериментального CatBoostRanker. Подробные команды, сетка и объяснения — [evaluation/README.md](evaluation/README.md).

Нужны исходный backup и локальная модель. Бинарные данные, эмбеддинги и исходная база в репозиторий не включены. Выполните импорт `build`, затем `embed` по инструкции в `README.md`. Для CatBoost установите `requirements-rank.txt`; исходная модель в `evaluation/results/` относится к одному хешу каталога и не должна применяться к другой версии. Скрипт эксперимента пересоздаст её для своего каталога.

Для ручного использования экспериментальной модели скопируйте `evaluation/results/catboost.cbm` в активную директорию `artifacts/catalog/<generation>/` и создайте рядом `catboost_meta.json` с `catalog_sha256`, `model_sha256`, `experimental: true`; хеши проверяются при каждом использовании. Затем: `PYTHONPATH=src .venv/bin/python -m alfa_reco search "хочу открыть кофейню" --mode catboost`. Базовый гибрид остаётся режимом по умолчанию.

Это исследовательское качество: нет логов показов и проверенных покупок, прибыли или настоящей персонализации. См. [фактические результаты](evaluation/results/report.json).
