# Исторический этап 3: полные тексты и CatBoost

Документ относится к первоначальному эксперименту; текущий запуск описан в [README](README.md), результаты новых проверок — в [аудите](docs/RANKING_AUDIT_2026-11-12.md).

На этом этапе появились индекс разрешённых текстов/уроков, признаки по полям и эксперимент `scripts/experiments.py` на 58 предварительно размеченных запросах. Исправленный отчёт находится в `evaluation/results_corrected/`. Этот скрипт оценивает внутренние списки retrieval, а не всю текущую пользовательскую политику.

Устаревшая инструкция ручного создания `catboost_meta.json` удалена: текущий runtime читает `catboost_small_meta.json` и дополнительно проверяет векторы, схему и параметры BM25. Создание совместимого артефакта описано в основном README. По умолчанию CLI теперь использует экспериментальный ансамбль; гибрид выбирается явно через `--mode hybrid`.
