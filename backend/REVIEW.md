# Проверка реализации — 15 ноября 2026

Исходная версия: `3e7dfba` (`KaNaP1A/alfa_hakaton`, main).
Ветка реализации: `feat/hackathon-backend`.

## Выполнено

- FastAPI API с OpenAPI/Swagger, регистрацией, входом, TTL и отзывом токена.
- SQLAlchemy: PostgreSQL и SQLite; профили, сессии, история, каталог, права доступа.
- HTTP-клиент существующего алгоритма: поиск, рекомендации, план, таймауты и ошибки.
- Независимый деморежим с вымышленными данными, явно отмеченный в API.
- Сопоставление материалов по `entity_key` и контроль `generation`.
- Проверка публикации и прав для каталога, подсказок, поиска, альтернатив, рекомендаций,
  истории и всего плана; закрытые данные из объяснений алгоритма не раскрываются.
- Подстановка названий, описаний, цен и ссылок только из доверенного каталога API.
- История формируется на сервере; повторные события идемпотентны.
- Полный атомарный импорт каталога и CLI выдачи/отзыва прав.
- CLI инвентаризации схемы исходной PostgreSQL без чтения значений и изменения базы.
- CORS для явно указанных frontend origins, лимит запросов и тела, request ID и логи без тел/токенов.
- Dockerfile, Compose, закреплённые зависимости, GitHub Actions и инструкция ручной проверки.

В Docker smoke выполнены регистрация, сохранение профиля, readiness, каталог, подсказки,
поиск, запись и повтор события, рекомендации, план, logout и проверка отзыва токена.
Закрытый демоматериал не попадал в выдачу. Временные контейнеры использовали отдельную тестовую БД.

Особенность облачной среды: для скачивания пакетов внутри Docker понадобился CA её HTTPS-прокси.
Он был передан через BuildKit secret во временной копии Dockerfile. TLS не отключался;
сертификат и временный Dockerfile не входят в репозиторий или слои образа.

## Что нельзя проверить без входных данных

- Настоящую E5/CatBoost-выдачу: совместимых закрытых артефактов нет в репозитории.
- Автоматическую синхронизацию таблиц исходного PostgreSQL-дампа: сам дамп и его схема не предоставлены.
  Реализован явный импорт доверенного каталога; конкретное преобразование источника требует его схемы.
- Подтверждённые покупки, подписки, возвраты и LMS-прогресс: внешних контрактов/источников нет.
  Пользовательские учебные события помечены `self_reported` и не выдают доступ.
- Расширенный Python-профиль алгоритма: поля сохраняются API, существующий внутренний HTTP-контракт
  использует только категории и историю. Это ограничение явно описано в README.

Проверка качества и роста продаж не подменяется успешными интеграционными тестами.
